# Code de conduite

Ce projet traite d'un texte sacré pour des centaines de millions de personnes. Nous attendons de chacun le respect dû à ce texte et aux personnes qui le récitent, l'étudient ou le relisent.

## Nos engagements

- **Être respectueux** : critiquer le code, les idées et les résultats, jamais les personnes. Accueillir les débutants.
- **Rester exact** : ne pas présenter comme établi ce qui ne l'est pas. Les chiffres citent leur source et leurs limites.
- **Respecter la vie privée et les droits** : aucun enregistrement de personne, voix tierce, adresse ou donnée personnelle partagés sans droit ni consentement.
- **Respecter le texte** : jamais de reformulation, de génération ou de « correction » du texte coranique ou de sa traduction officielle. Une erreur dans une source se signale, elle ne se corrige pas en silence.

## Ce qui n'est pas acceptable

Harcèlement, insultes, propos discriminatoires, attaques personnelles, publication d'informations privées, moquerie du texte ou des pratiques religieuses, polémique hors sujet dans les issues et les PR.

## Application

Les mainteneurs peuvent modérer, modifier ou supprimer tout commentaire, issue ou PR contraire à ce code, et bloquer l'accès à son auteur en cas de manquement répété ou grave. Pour signaler un comportement, utilisez le signalement privé décrit dans [SECURITY.md](SECURITY.md) ou un message privé à un mainteneur sur GitHub. Les signalements sont traités avec discrétion.

Ce code s'applique à tous les espaces du projet (dépôt, issues, discussions, PR). Il s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
